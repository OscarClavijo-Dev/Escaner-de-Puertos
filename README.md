# 🔍 Port Scanner - Aplicación de Escritorio en Python

Aplicación de escritorio desarrollada en Python que permite escanear puertos TCP comunes de una dirección IP y detectar cuáles están abiertos.

Proyecto educativo para aprender fundamentos de:
- Redes
- Programación en Python
- Multihilos
- Interfaz gráfica
- Ciberseguridad básica

---

## 🖥️ Funcionalidades

- Interfaz gráfica (Tkinter)
- Escaneo rápido de puertos TCP
- Barra de progreso en tiempo real
- Muestra solo puertos abiertos
- Aplicación ejecutable (.exe)
- No requiere VS Code

---

## 🧰 Tecnologías utilizadas

- Python 3
- Tkinter
- socket
- concurrent.futures
- PyInstaller

---

## 🚀 Uso de la aplicación

### Opción 1: Ejecutar como aplicación de escritorio

1. Ir a la carpeta `dist`
2. Ejecutar `portscanner.exe`
3. Ingresar una IP
4. Presionar “Escanear”

---

### Opción 2: Ejecutar desde código fuente

Requisitos:
- Python 3 instalado

Ejecutar:
**CMD o bash***
python portscanner.py
